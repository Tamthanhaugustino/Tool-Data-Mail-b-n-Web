Sitemap

Web app gồm 3 vùng: public (login/forgot), main app (sau khi đăng nhập), và admin panel riêng cho owner. Sidebar chính có 9 mục cho user thường + 3 mục admin-only.

Primary path Login → Dashboard → Saved Leads là quãng đường dài nhất user đi. UI ưu tiên 2 nhánh: Discovery & Domain Scan, gặp nhau tại Results → Saved Leads.
