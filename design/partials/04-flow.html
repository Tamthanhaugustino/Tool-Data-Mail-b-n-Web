04 · User flow

User flow chính

Flow chuẩn: Login → Cấu hình API key → chọn Discovery hoặc Domain Scan → Preview → Scan → Results → Save → Export. Phần preview/cảnh báo trước khi tốn quota là checkpoint bắt buộc.

Edge flows quan trọng

  1. API key chưa cấu hình — Dashboard hiện warning card vàng. Khi user click Keyword Discovery/Domain Scan mà thiếu key tương ứng, redirect inline về Settings + alert giải thích key đó dùng làm gì.
  2. Quota gần hết — Topbar hiện badge cam API · 78/100. Khi limit cao trong Preview → alert đỏ chặn button Scan, bắt user xác nhận lại.
  3. Scan timeout / partial fail — Hiển thị mixed-state ở Results (vd: 23/30 domain xong, 7 failed). User có thể "Retry failed" mà không scan lại toàn bộ.
  4. Session hết hạn — Modal nhẹ "Phiên đăng nhập hết hạn" + button "Đăng nhập lại" — giữ context page hiện tại để quay lại sau login.
  5. Khách hàng mới (zero state) — Sau lần login đầu, Dashboard show "Bắt đầu trong 3 bước" thay vì recent activity rỗng.
