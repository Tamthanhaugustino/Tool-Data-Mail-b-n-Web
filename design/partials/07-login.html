SCREEN 1/11 Login · Public · Path: /login
1
Trái — preview dashboard. Mục đích: tạo cảm giác sản phẩm "có thật", show ngay điều khách sẽ thấy sau khi đăng nhập. Lead card có confidence badge để gợi giá trị cốt lõi. Trên mobile sẽ ẩn panel này.
2
Form đăng nhập gọn — Email + password + remember. Không có Sign up vì account do admin cấp. Có Google OAuth dự phòng (có thể tắt bằng feature flag).
3
Quên mật khẩu → trang /forgot (nhập email → check inbox → /reset/:token). Reuse layout login.
4
Footnote "Liên hệ admin" — đường mailto hoặc form trợ giúp, vì chưa làm self-serve signup.
5
Error states. (a) Sai mật khẩu → input password đỏ + alert đỏ trên đầu form "Email hoặc mật khẩu chưa đúng." (b) Tài khoản bị khoá → alert vàng "Tài khoản tạm khoá. Liên hệ admin." (c) Quá nhiều lần thử → captcha sau lần 5.

Phụ thuộc

  • Forgot password page (/forgot) và Reset password (/reset/:token) — dùng cùng layout split này; phía phải chỉ đổi nội dung form.
  • Sau khi login thành công, redirect /dashboard. Nếu user có deep-link query ?return=/results/42 thì honor.
  • Refresh token tự gia hạn trong 30 ngày nếu user tick "Ghi nhớ thiết bị".
