SCREEN 2/11 Dashboard · Path: /dashboard · Above the fold: greeting + 4 stat + 4 quick action.
1
Greeting cá nhân. Có ngày để user thấy app đang "live", và emoji vẫy tay duy nhất ở đây (không dùng emoji ở chỗ khác).
2
4 stat card — không lạm dụng chart. Chỉ số chính có delta so kỳ trước (xanh / đỏ). Quota Hunter có denominator để user thấy ngữ cảnh.
3
4 quick action — Discovery, Domain Scan, Saved Leads, Export. Mỗi card 1 màu accent khác để dễ phân biệt nhanh. Toàn bộ card đều click được.
4
Trạng thái workspace — checklist 4 mục. Khi chưa cấu hình API key, item đó hiện badge cam "Cần kết nối" + button "Thiết lập ngay".
5
Recent activity — 5 mục mới nhất, mix giữa 4 loại: Domain Scan, Keyword Discovery, Save Lead, Export. Click vào → mở context tương ứng (vd: click vào scan → mở Results của run đó).

Zero state · user mới

Khi user mới (chưa scan lần nào): thay khu vực Recent activity bằng card "Bắt đầu trong 3 bước" (1) Cấu hình API key → (2) Scan đầu tiên → (3) Lưu lead. Stat card hiển thị "—" hoặc "Chưa có dữ liệu" thay cho số.

Khi chưa có API key

Trên cùng page xuất hiện Alert warning bám fixed dưới topbar: "Bạn cần thêm Hunter.io API Key để bắt đầu quét email. Mở Settings →"
