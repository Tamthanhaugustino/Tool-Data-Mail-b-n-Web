Khi bạn muốn dùng Keyword Discovery để tìm website công ty từ keyword + quốc gia. Nếu bạn chỉ có sẵn danh sách domain, chỉ cần Hunter.io.

API key của bạn được bảo mật.

Khoá được mã hoá khi lưu vào database (AES-256). Tool Data Mail không chia sẻ key cho bên thứ ba. Không chia sẻ key với người khác — kẻ xấu có thể tiêu hết quota của bạn.

SCREEN 3/11 Settings · API Keys · Path: /settings/api · Tab Settings có 5 tab: API Keys (mặc định), Tài khoản, Đổi mật khẩu, Notifications, Bảo mật.
1
Mỗi key có icon riêng & màu (Hunter cam, SerpAPI tím) để user nhớ. Card head có status badge bên phải.
2
Giải thích "dùng để làm gì" inline — sub trong card-head + alert info bên dưới input. UX rule #2 từ brief.
3
Sau khi save → mask. Hiển thị 24 dots + 4 ký tự cuối real. Có nút "Hiện" (tạm bỏ mask trong 5 giây) và "Copy".
4
Quota panel chỉ hiện khi Hunter đã connect (Hunter API trả về quota). SerpAPI thường không trả quota qua API → không hiện.
5
Test connection button — gọi 1 request ping, không tốn quota nếu có thể. Sau khi test, lưu timestamp + response time vào panel "Test gần nhất".
6
Save flow. (a) User dán key → click "Lưu & Test" → spinner. (b) Test pass → toast "Đã kết nối Hunter.io", badge chuyển xanh, key mask. (c) Test fail → input đỏ + helper text "Key không hợp lệ. Kiểm tra lại trên hunter.io." Không lưu.
7
Security note ở cuối page — UX rule #1 từ brief, nhắc về bảo mật. Dùng icon shield + tone tích cực ("được bảo mật") trước, cảnh báo ("không chia sẻ") sau.

Tab khác (ngắn gọn)

  • Tài khoản — Tên, avatar (upload), email (read-only nếu là email login), múi giờ, ngôn ngữ.
  • Đổi mật khẩu — Mật khẩu cũ + mới + xác nhận. Hiện strength meter.
  • Notifications — Email khi (a) scan xong, (b) export sẵn sàng, (c) quota gần hết, (d) hoá đơn.
  • Bảo mật — 2FA, active sessions (logout từ thiết bị khác), lịch sử đăng nhập 30 ngày.
