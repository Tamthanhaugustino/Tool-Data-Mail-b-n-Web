2
Cột Loại — badge phân biệt rõ Keyword (xanh) và Domain Scan (teal). Có icon.
3
Cột Input — show input gọn + thông tin phụ (Keyword/region hoặc số domain + nguồn). Linked run "từ Keyword #041" tạo trace giữa 2 flow.
4
Status badge — Xong (xanh) · Có lỗi (vàng) · Thất bại (đỏ) · Đang chạy (info có dot pulse).
5
Action cuối row — "Mở Results" (primary, dẫn về /results/:id), icon download (re-download CSV/JSON), menu more (Xoá, Đổi tên, Chạy lại).
6
Run thất bại giữ trong history với reason ("Hunter quota hết"). Button "Chạy lại" → quay về Domain Scan với cùng input điền sẵn.

History detail (sub-screen)

Click vào Run ID → page detail với: timeline (started/finished/cancelled), input đầy đủ, 4 stat (domain, email, error, request used), preview 10 row đầu của results, button "Mở Results đầy đủ", "Re-download CSV", "Re-download JSON", "Xoá run này".
