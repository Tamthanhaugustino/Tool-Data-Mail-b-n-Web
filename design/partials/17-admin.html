Theme tối + accent tím để admin panel cảm khác hẳn customer app. Sidebar dark slate, brand mark đổi tím, badge ADMIN gradient tím. Tránh nhầm lẫn khi đang demo cho khách.
2
4 admin stat — Tổng user · Active 30d · MRR · API spend. MRR hiển thị VND, API spend USD (vì Hunter/SerpAPI bill USD).
3
Filter theo plan + status — chip ngang, click apply filter ngay (giống Saved Leads).
4
Row user — avatar + tên + email; plan badge với gradient màu khác nhau (Trial cam, Basic xanh, Pro vàng, Agency tím); usage stat (scan/lưu, API %); login gần nhất + ngày tạo.
5
Anomaly highlight — row spam (đã khoá) có 11 scan nhưng 0 saved + API usage cao 98% → bị flag và disable. Admin có thể delete hoặc unlock.
6
Action "Mở" → trang detail user: profile, subscription, scan history của user đó, action thủ công (đổi plan, reset password, khoá / mở khoá, xoá).

Trang admin khác (ngắn)

  • Usage — biểu đồ scan / day, API spend / day, top 10 user theo usage.
  • Plans & Pricing — edit limit của từng plan, ra mã activation thủ công.
  • All scans — global view mọi scan, lọc theo user / status / loại.
  • Audit log — mọi action admin: ai đổi plan của ai, khi nào — for compliance.
  • Settings — env config, Hunter / SerpAPI default key cho user trial, email templates.
