09 · Pattern

Responsive behavior

Web app desktop-first (tool sales / marketing chủ yếu dùng máy tính), nhưng phải dùng được trên tablet & mobile để xem Saved Leads, check notification, export khi đi đường.

Breakpoints

📱 Mobile
< 640px
  • Sidebar → drawer slide từ trái (button menu trên topbar)
  • Topbar: chỉ logo + menu + avatar (ẩn search global; thay bằng icon search → mở fullscreen overlay)
  • Table → card list (mỗi lead = 1 card stacked)
  • Stat card: 1 cột, full width
  • Quick action: 2x2 grid
  • Filter sidebar → bottom sheet drawer
📱 Tablet
640 – 1023px
  • Sidebar rail (chỉ icon, width 64px). Click → bung ra 240px overlay
  • Table giữ nguyên nhưng có horizontal scroll, sticky cột email
  • Filter sidebar collapse mặc định (button "Filter")
  • Stat card: 2x2 grid
  • Domain Scan: form Input / Options stack thành 2 row
💻 Desktop
1024 – 1439px
  • Sidebar full 240px, topbar 60px (mặc định)
  • Main max-width: container đầy
  • Stat card: 4 cột
  • Filter sidebar mở mặc định (240px)
  • Table: tất cả cột hiển thị
🖥 Large
≥ 1440px
  • Main max-width 1440px, căn giữa (white-space hai bên)
  • Dashboard 2 cột grid 1.05fr / 1fr cho setup status + activity
  • Cho phép Drawer chi tiết lead width 520px (rộng hơn mặc định 480)
  • Khả năng split-view: Results bên trái + Lead detail mở trực tiếp bên phải

Patterns đáng chú ý

  • Table → Card list trên mobile. Mỗi card show 3 dòng: tên + email · công ty + chức vụ · status + tag. Tap → full detail.
  • Floating Action Button (FAB) cho action chính ở mobile (Export, Save…), pinned bottom-center.
  • Sticky email column khi horizontal scroll trên tablet — email là kết nối chính.
  • Bottom sheet thay modal trên mobile cho Filter, Export, Lead detail.
  • Topbar 48px trên mobile (thay 60px desktop), tăng diện tích nội dung.
  • Touch target ≥ 44px cho mọi button, badge, row action.
