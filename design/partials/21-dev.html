Developer handoff notes

Notes dành cho Cursor / FE engineer triển khai. Đọc kèm với từng screen. Stack giả định: Vite + React 18 + TypeScript · UI: shadcn/ui + Tailwind · state: TanStack Query · routing: React Router hoặc Next.js App Router.

Stack & conventions

  1. 1
    UI primitives — chuyển từng component ở § 6 sang shadcn/ui equivalent: Button, Input, Select, Switch, Checkbox, Badge, Tabs, Tooltip, Dialog, Sheet (Drawer), Sonner (Toast), Skeleton. Override token theo § 2 (chỉnh tailwind.config.ts + globals.css).
  2. 2
    Iconography — npm i lucide-react. Default strokeWidth={2} · size 18 trong nav, 16 trong button, 14 trong cell.
  3. 3
    Font — Geist + Geist Mono từ Google Fonts. Preload bằng next/font hoặc <link rel="preconnect">.
  4. 4
    Data fetching — TanStack Query với staleTime: 30s cho list, refetchOnWindowFocus: true cho quota stat. Long-running scan dùng SSE / WebSocket hoặc poll /api/runs/:id/progress mỗi 1s.
  5. 5
    Form — react-hook-form + zod. Validate domain regex client-side TRƯỚC khi gửi Preview (xem § 3.5).
  6. 6
    i18n — react-i18next ngay từ đầu, dù chỉ có VN. Mọi copy ở § 10 đi vào vi.json.

Data shapes (rút gọn)

type Lead = {
  id: string;
  email: string;
  firstName?: string; lastName?: string; fullName?: string;
  position?: string; department?: string; seniority?: 'junior' | 'mid' | 'senior' | 'c-level';
  company: string; domain: string;
  confidence: number;             // 0–100
  status: 'verified' | 'accept_all' | 'invalid' | 'webmail';
  sources: string[];              // e.g. ['website-team', 'linkedin']
  // CRM fields (chỉ có khi đã saved)
  saved?: {
    leadStatus: 'new' | 'contacted' | 'interested' | 'customer' | 'not_relevant';
    tags: string[]; note: string;
    savedAt: ISODate; updatedAt: ISODate;
  };
  runId: string;                  // run nào tìm ra
};

type ScanRun = {
  id: string;                     // 'r-2026-05-18-042'
  type: 'keyword' | 'domain';
  status: 'queued' | 'running' | 'done' | 'failed' | 'cancelled';
  input: { keyword?: string; country?: string; domains?: string[]; limit?: number };
  options: { verifiedOnly: boolean; skipCatchAll: boolean; skipWebmail: boolean };
  stats: { total: number; done: number; emailsFound: number; errors: number; apiUsed: number };
  startedAt: ISODate; finishedAt?: ISODate;
  error?: { code: string; message: string };
};

Realtime scan progress

  1. 1
    Khi user bấm "Bắt đầu scan": POST /api/scan/start trả về runId ngay (job background).
  2. 2
    Redirect sang /scan/running/:runId.
  3. 3
    Subscribe progress: GET /api/runs/:id/stream (SSE) lý tưởng. Fallback poll GET /api/runs/:id mỗi 1s. Mỗi event: { done, total, emailsFound, errors, latestDomain, status }.
  4. 4
    Khi status === 'done': hiện toast "Scan xong: {n} email" + tự redirect /results/:runId sau 2s (hoặc click "Xem kết quả →" ngay).
  5. 5
    Khi user đóng tab: backend vẫn chạy; notification gửi qua email + cập nhật bell icon khi user quay lại.

Performance & UX guardrails

  • Bảng Results / Saved Leads dùng virtualization khi > 200 row (TanStack Virtual).
  • Filter sidebar update count chỉ thay đổi sau debounce 200ms khi user gõ vào tìm kiếm.
  • Export CSV: backend stream để không OOM với 5.000+ lead. UI hiển thị progress nếu > 3s.
  • Mobile data table → switch sang card list ở < 640px (xem § 9). Không cố gắng squeeze table desktop.
  • Mọi action có thể tốn quota (Find websites, Start scan, Test connection) không bao giờ gọi API chỉ vì user click vu vơ — luôn có user gesture rõ ràng.
  • Optimistic UI cho: Save lead, Đổi status, Đổi tag, Edit note. Toast confirm khi server xong; rollback nếu fail.

Accessibility

  • Mọi icon-only button có aria-label tiếng Việt.
  • Color contrast: kiểm tra confidence badge dưới mức 50% phải đủ AA (test với plugin).
  • Keyboard nav cho table: ↑↓ chuyển row, Space tick, ⌘ A chọn tất cả page hiện tại, ⌘ E export.
  • Focus ring 2px solid primary-600 với offset 2px — không tắt outline.
  • Modal có focus trap, Esc đóng, return focus về trigger.

Security & storage

  • API key (Hunter, SerpAPI) mã hoá AES-256 trước khi vào DB. Decrypt chỉ ở request time để gọi API thứ ba.
  • Không bao giờ trả key thật về frontend — chỉ mask •••a3d2.
  • JWT lưu httpOnly cookie, không localStorage.
  • CSRF token cho mọi mutation.
  • Rate limit: login 5/min, forgot 1/min, scan start 10/h, export 30/h.
  • Audit log mọi admin action vào table audit_log (ai, làm gì, lên user nào, lúc nào, IP).

Phase rollout (đề xuất)

  1. P1
    MVP · 3–4 tuần. Login, Dashboard, Settings · API Keys, Domain Scan (4 steps), Results, Saved Leads, Export, History. Tiếng Việt + desktop only.
  2. P2
    2 tuần. Keyword Discovery, Subscription page (manual activation), Notifications email, Admin Users.
  3. P3
    2 tuần. Mobile responsive, drawer/sheet, virtualization, optimistic UI, SSE live scan.
  4. P4
    Sau đó. Payment online (Stripe / VNPay), API truy cập lead cho Agency plan, Email outreach module, team workspace.
